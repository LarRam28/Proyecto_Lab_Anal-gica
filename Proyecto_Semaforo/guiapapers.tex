\begin{abstract}

En este proyecto se desarrolló un sistema de semáforo vehicular y peatonal mediante el uso de lógica digital y circuitos electrónicos analógicos. El sistema implementa un contador decreciente encargado de controlar los tiempos de operación del semáforo, así como un subsistema de visualización y señalización auditiva para el paso peatonal. 

El diseño incorpora diferentes bloques funcionales, entre ellos una etapa de alimentación a partir de 120\,V, un generador de reloj basado en un temporizador 555, lógica secuencial para el control de estados, circuitos de visualización mediante displays de siete segmentos y un sistema de audio configurado para alertar al peatón durante los últimos segundos del conteo.

Para el desarrollo del proyecto se emplearon componentes TTL y dispositivos discretos, considerando criterios de disponibilidad, simplicidad de implementación y compatibilidad entre etapas. El comportamiento del sistema fue validado mediante simulaciones y pruebas experimentales, obteniéndose un funcionamiento estable en las transiciones de estado, el conteo regresivo y la generación de señales visuales y auditivas.

\end{abstract}

\begin{IEEEkeywords}
Semáforo vehicular, semáforo peatonal, lógica digital, contador decreciente, temporizador 555, displays de siete segmentos, señalización auditiva.

\section{Introducción}

\IEEEPARstart{E}{n} el presente proyecto se diseñó e implementó un sistema de semáforo vehicular y peatonal utilizando componentes electrónicos analógicos y digitales. El sistema incorpora una etapa de alimentación, un generador de reloj, un contador decreciente, una máquina de estados encargada de administrar la secuencia del semáforo, una etapa de visualización mediante displays de siete segmentos y un subsistema de audio orientado a la señalización peatonal.

Para el desarrollo del proyecto se utilizaron temporizadores 555, compuertas lógicas, flip-flops tipo D, transistores y contadores TTL, seleccionados de acuerdo con criterios de disponibilidad, facilidad de implementación y compatibilidad eléctrica entre dispositivos. Además, se consideraron aspectos relacionados con la estabilidad de las señales de reloj, la sincronización de estados y el control adecuado de las salidas visuales y auditivas.

El sistema fue desarrollado y verificado mediante simulación electrónica, lo cual permitió analizar el comportamiento individual de cada bloque y su interacción dentro del circuito completo antes de la implementación física. Esta etapa de validación permitió identificar consideraciones de diseño relacionadas con la sincronización de señales, la temporización del conteo, la activación de salidas visuales y la generación de alertas auditivas.

\subsection{Contador Decreciente}

El bloque de conteo se implementó mediante dos contadores BCD 74LS192 configurados en modo decreciente, tal como se muestra en la Figura~\ref{Contador_50}. El contador superior corresponde a las unidades, mientras que el contador inferior corresponde a las decenas, permitiendo representar el conteo desde 50 hasta 00.

\begin{figure}[H]
\centering
\includegraphics[width=3in]{Contador_50}
\caption{Bloque del contador decreciente de 50 a 00}
\label{Contador_50}
\end{figure}

La carga inicial se realiza mediante la entrada \textit{LOAD}, utilizando un circuito RC junto con inversores 7404. Este arreglo permite cargar automáticamente el valor inicial al energizar el circuito y, posteriormente, liberar los contadores para iniciar el conteo.

La señal de reloj se conecta a la entrada \textit{DOWN} del contador de unidades, por lo que cada pulso disminuye su valor. Cuando este contador completa su ciclo, su salida \textit{BO} se utiliza para activar el conteo decreciente del contador de decenas. De esta forma, las decenas solo cambian cuando las unidades pasan por todo su ciclo, permitiendo obtener una secuencia decimal correcta.

Para controlar el avance del sistema se emplean dos compuertas AND. La primera recibe como entradas la señal de reloj y \texttt{Reset\_00}; por lo tanto, solo permite el paso del reloj cuando el contador se encuentra en un valor diferente de 00 o cuando existe una activación proveniente de los botones. Esto evita que, al llegar a 00, el contador continúe hacia 99.

La segunda compuerta AND recibe la señal \texttt{FFD\_En}, proveniente del flip-flop D de habilitación, junto con \texttt{Reset\_00}. Esta compuerta se encarga de habilitar el funcionamiento general del bloque contador únicamente cuando el sistema ha sido activado y la condición de conteo es válida.

La señal \texttt{Reset\_00} se obtiene a partir de la detección del estado 00 y de la activación de los botones. Mientras el conteo sea diferente de 00, esta señal permite que el sistema continúe operando. Al llegar a 00, se bloquea el reloj y el contador permanece detenido hasta que una nueva activación permita iniciar otro ciclo.

Las salidas \texttt{U\_A}--\texttt{U\_D} y \texttt{D\_A}--\texttt{D\_D} entregan los cuatro bits BCD correspondientes a unidades y decenas, respectivamente.

\subsection{Visualización}

El sistema de visualización se implementó mediante dos decodificadores BCD a siete segmentos CD4511, encargados de convertir las salidas binarias provenientes del contador en las señales necesarias para controlar los displays de siete segmentos, tal como se muestra en la Figura~\ref{Decodificador_50}. Estos integrados fueron seleccionados debido a que permiten simplificar la conexión entre las salidas BCD del contador y los segmentos del display, evitando implementar una lógica combinacional adicional para cada segmento.

\begin{figure}[H]
\centering
\includegraphics[width=3in]{Decodificador_50}
\caption{Bloque decodificador para visualización}
\label{Decodificador_50}
\end{figure}

Las señales \texttt{U\_A}--\texttt{U\_D} y \texttt{D\_A}--\texttt{D\_D}, correspondientes a los cuatro bits BCD de unidades y decenas generados por el contador decreciente, se conectan directamente a las entradas de cada decodificador CD4511. A partir de estas entradas, cada integrado genera las señales \texttt{A}--\texttt{G} necesarias para activar los segmentos correspondientes de cada display.

La visualización únicamente se habilita cuando el semáforo peatonal se encuentra en verde, es decir, durante el conteo de 30 segundos asociado al cruce peatonal. Para esto se utiliza la señal \texttt{Contador\_30}, proveniente de la máquina de estados del sistema. Esta señal se almacena mediante un flip-flop tipo D 7474, el cual permite mantener estable la habilitación de los displays durante todo el intervalo de visualización.

El flip-flop 7474 fue utilizado debido a que permite conservar el estado lógico de habilitación y evitar que los displays dependan únicamente de un pulso momentáneo. Además, se incluye una compuerta NOT para adaptar la señal de control según la lógica requerida por las entradas de habilitación del decodificador.

Tanto los decodificadores CD4511, de tecnología CMOS, como el flip-flop 7474, de tecnología TTL, fueron alimentados con $5\,V$. Este valor se seleccionó porque corresponde a un punto de operación adecuado para la familia TTL y también se encuentra dentro del rango permitido para los dispositivos CMOS utilizados, facilitando la compatibilidad eléctrica entre las etapas del sistema.

Las salidas de los decodificadores se conectan finalmente a los displays de siete segmentos, encargados de representar visualmente el conteo regresivo del sistema peatonal, tal como se observa en la Figura~\ref{Deco_Seg}.

\subsection{Audio}

El subsistema de audio se divide en tres etapas funcionales, tal como se aprecia en la Figura~\ref{Montaje_audio}:

\begin{enumerate}
    \item Etapa de control lógico: recibe las señales \textit{Pv}, \textit{5s} y \textit{0s} provenientes de la FSM, encargadas de habilitar el oscilador. Además, incorpora compuertas NOR configuradas como un \textit{SR Latch}, utilizado para seleccionar la frecuencia de operación.

    \item Etapa de oscilación: implementada mediante un temporizador 555 en modo astable, acompañado de una red RC seleccionable a través del transistor Q2 (2N3904), permitiendo ajustar la frecuencia de salida.
    
    \item Etapa de salida: la señal cuadrada generada en la salida \textit{OUT} del temporizador 555 se dirige hacia la salida \textit{Out Audio}, para su posterior amplificación mediante un circuito transistorizado externo encargado de excitar el parlante.
\end{enumerate}

\begin{figure}[H]
\centering
\includegraphics[width=3in]{Montaje_audio}
\caption{Diagrama del bloque de audio}
\label{Montaje_audio}
\end{figure}

Las compuertas NOR del integrado 7402 procesan las señales digitales de
control: \texttt{5s} (señal que se activa
en los últimos 5\,s del conteo peatonal) y \texttt{0s} (señal de fin de
ciclo). La combinación lógica implementada junto con la señal proporcionada por la FSM de \texttt{Pv} (señal activa cuando el semáforo peatonal esta en verde) garantiza que:
 
\begin{itemize}
  \item El oscilador queda habilitado únicamente cuando el paso peatonal
        está activo (\texttt{Pv} en estado correspondiente).
  \item La señal de base de Q2 se activa en los últimos 5\,s (señal
        \texttt{5s} activa), modificando la resistencia efectiva del
        temporizador y aumentando la frecuencia del tono.
\end{itemize}
 
\subsubsection{Transistor (Q2 — 2N3904)}

Las compuertas NOR se configuran como un SR Latch, cuya función es
almacenar el estado lógico asociado a la señal de 5 segundos. Esto permite
mantener la salida en nivel alto aun después de finalizar el pulso que lo activa,
conservando dicho estado durante el tiempo requerido por el sistema.
La salida del SR Latch se conecta a la base del transistor Q2,
permitiendo controlar su estado de conducción. De esta manera, se garantiza
que Q2 permanezca activado durante los 5 segundos establecidos, manteniendo
la configuración correspondiente del circuito oscilador.

El transistor Q2 opera en la región de corte/saturación como interruptor
electrónico. La resistencia de base $R_2=220\,\Omega$ limita la corriente
de base para garantizar la saturación. Cuando Q2 conduce, habilita un
segundo capacitor en paralelo con $C_1$ ($0{,}22\,\mu F$), obteniéndose una
capacitancia equivalente de $0{,}44\,\mu F$. El incremento en la capacitancia
aumenta el tiempo de carga y descarga del temporizador 555, reduciendo la
frecuencia de oscilación y produciendo el tono de menor frecuencia.

Cuando Q2 permanece en corte, únicamente participa el capacitor
$C_1$ ($0{,}22\,\mu F$), dando lugar a una frecuencia de oscilación mayor,
correspondiente al tono rapido.
 
\subsubsection{Temporizador 555 en Modo Astable}
 
El temporizador NE555 se encuentra configurado en modo astable, generando una
onda cuadrada continua cuya frecuencia depende de la red RC externa.
Para determinar el período de oscilación se emplea la siguiente ecuación:

\begin{align}
T &= 0.693(R_A + 2R_B)C
\label{eq:periodo}
\end{align}

A continuación, se analiza el comportamiento del circuito para las dos
configuraciones posibles del capacitor:

\begin{enumerate}

\item Caso 1: se encuentran conectados ambos capacitores,
obteniéndose una capacitancia equivalente de
$0{,}44\,\mu F$

\begin{align*}
T &= 0.693\left(100\,k\Omega + 2(850\,k\Omega)\right)
(0{,}44\,\mu F)\\
T &\approx 0{,}549\,s\\
T &\approx 549\,ms
\end{align*}

\item Caso 2: únicamente se encuentra conectado el capacitor
$C_2 = 0{,}22\,\mu F$

\begin{align*}
T &= 0.693\left(100\,k\Omega + 2(850\,k\Omega)\right)
(0{,}22\,\mu F)\\
T &\approx 0{,}274\,s\\
T &\approx 274\,ms
\end{align*}

\end{enumerate}

Resultado de la simulación se tiene aproximadamente los mismos valores, 
la señal de salida del 555 se observa en la Figura~\ref{Senal_audio}. Como se puede 
observar, hay un aumento en la frecuencia en los últimos 5s.

\begin{figure}[H]
\centering
\includegraphics[width=3in]{Señal_audio}
\caption{Salida del bloque de audio}
\label{Senal_audio}
\end{figure}

La frecuencia de oscilación para cada caso se obtiene a partir de la relación entre frecuencia y período:

\begin{align}
f &= \frac{1}{T}
\label{eq:frecuencia}
\end{align}

Aplicando la ecuación anterior para cada configuración:

\begin{enumerate}

\item Caso 1: capacitancia equivalente de $0{,}44\,\mu F$

\begin{align*}
f &= \frac{1}{549\,ms}\\
f &= \frac{1}{0{,}549\,s}\\
f &\approx 1{,}82\,Hz
\end{align*}

\item Caso 2: capacitancia de $0{,}22\,\mu F$

\begin{align*}
f &= \frac{1}{274\,ms}\\
f &= \frac{1}{0{,}274\,s}\\
f &\approx 3{,}65\,Hz
\end{align*}

\end{enumerate}

Estas frecuencias producen los tonos de bip adecuads para la señalización durante el paso peatonal normal.
Este ajuste queda sujeto a cambios posteriores al prototipo físico.

\subsubsection{Salida del bloque}

La salida del subsistema de audio corresponde a una señal de onda cuadrada
generada por el temporizador NE555. Mediante las configuraciones descritas
anteriormente, es posible modificar la frecuencia de oscilación de dicha
señal, permitiendo la generación de distintos tonos de audio según el estado
del sistema.

La señal de salida se conecta a la base de un transistor encargado
de funcionar como etapa de amplificación y adaptación de potencia, tal como
se muestra en la Figura~\ref{Parlante}. De esta manera, el transistor actúa
como una interfaz entre la señal de control proveniente del NE555 y la carga
de salida.

Debido a las variaciones posibles en la implementación física, algunos parámetros pueden 
requerir ajustes posteriores durante la etapa de ensamblaje y pruebas experimentales.
